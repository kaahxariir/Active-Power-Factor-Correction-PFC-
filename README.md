# Active-Power-Factor-Correction-PFC-
Designed and developed a 1.3 kW Active PFC board tailored for motor driver applications to ensure compliance with power quality standards like IEEE 519 and IEC 61000-3-2. While passive capacitors can correct the displacement power factor caused by inductive loads, they cannot mitigate the harmonic distortion introduced by nonlinear rectifiers. To address this, I implemented an Active PFC stage using a Boost converter operating in Continuous Conduction Mode (CCM). This approach was selected for the 1.3 kW power level to minimize current ripple and improve efficiency compared to CRM or DCM topologies. Although CCM introduces higher turn-on losses due to diode reverse recovery, the design successfully balances high power density with a near-sinusoidal input current, effectively optimizing the interface between the grid and the motor drive system.
